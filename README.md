# Adithyan. S. R — Portfolio

A responsive, single-page portfolio for Adithyan. S. R, B.Tech CSE (Artificial Intelligence) student at Joy University.

## Run locally

Open `index.html` in any modern browser. No build step or package installation is required.

## Deploy free with GitHub Pages

1. Create a new public repository named `adithyan-portfolio` in the GitHub account `adithyansr3405-jpg`.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then click **Save**.
6. Wait a minute or two. The site should appear at `https://adithyansr3405-jpg.github.io/adithyan-portfolio/`.
