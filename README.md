# Adithyan — Portfolio Website

A responsive, single-page developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.
3. For a local server, open this folder in VS Code and use the Live Server extension.

## Publish free with GitHub Pages
1. Create a new public GitHub repository named `adithyansr3405-jpg.github.io` (or another repository name).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. The site URL will be `https://adithyansr3405-jpg.github.io/` if the repository has that exact name; otherwise it will be `https://adithyansr3405-jpg.github.io/REPOSITORY-NAME/`.

## Before publishing
- Confirm the preferred public name and spelling.
- Add a professional email / LinkedIn URL if Adithyan wants them public.
- Add a real profile photo if desired.
- Review the project descriptions and skill list for accuracy.
- The featured project currently links to the public GitHub repository. If the game has a live playable URL, replace the repository link with that URL too.

## Notes
- No framework or build step is required.
- Google Fonts are loaded from the web; system fallbacks are included.
- The portfolio links to public GitHub repositories and does not invent contact details or professional experience.
